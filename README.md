Amazon Sales Analysis Dashboard

📊 Project Overview

This project is an interactive Amazon Sales Analysis Dashboard created using Tableau.

The dashboard analyzes sales performance, customer activity, product performance, payment methods, order status, and other business metrics to generate meaningful insights from Amazon sales data.

🎯 Project Objectives

Analyze overall sales performance

Track total orders and customers

Analyze product and category performance

Identify sales trends over time

Analyze payment methods and order status

Evaluate discounts, taxes, and shipping costs

Generate business insights using interactive dashboards

📊 Dashboards

1. Amazon Sales Overview

Provides an overall view of Amazon sales performance including sales, orders, customers, quantity sold, product/category analysis and monthly trends.



2. Product Analysis

Analyzes product-level performance using metrics such as Average Order Value, Average Selling Price, Total Discount and Total Shipping Cost.



3. Product Performance Analysis

Provides insights into total products, brands, quantity sold and tax performance.



4. Payment & Order Analysis

Analyzes payment methods, order statuses, categories and yearly performance.



🔍 Key Calculations

Average Order Value (AOV)

AOV = Total Sales / Total Orders

Gross Sales

Gross Sales = Unit Price × Quantity
